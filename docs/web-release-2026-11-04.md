## Первопричины

- Пересекавшиеся мобильные правила на 768 px, слишком позднее сворачивание двух колонок корзины и несжимаемые внутренние элементы. Удалена глобальная маскировка overflow-x; корзина становится одноколоночной до 1024 px, счётчики сохраняют кнопки 44 px, popover ограничен экраном и высотой.
- У формы stack отсутствовала компоновка. Добавлены явные интервалы; полный телефон проверяется до запроса и сервером, OTP поддерживает вставку с разделителями, изменение номера и повторную отправку. Исправлен начальный/возвратный фокус. Реальных SMS не отправляли.
- Гостевая корзина придумывала магазин и pickup=true, а страница держала устаревающую копию provider cart. Теперь metadata обновляются по реальным stores, режим/магазин/адрес сохраняются вместе. Расчёт порций, добавок, округления и итогов общий, включая несколько групп.
- Ссылка баннера строилась без проверки товара. Уникальные цели проверяются на сервере с публичным кэшем; баннер недоступного товара исключается без замены картинки/ссылки. Реклама отделена от подборок, контраст заголовка задан явно.
- Глобальный loading запускал поток до проверки отсутствующего товара и давал HTTP 200 с текстом 404. Loading ограничен личным кабинетом; прямой отсутствующий товар возвращает HTTP 404.
- Общие sizes завышали запросы изображений. Уточнены реальные размеры и native auto для lazy; secondary API на главной вынесены в независимые Suspense. Публичные данные кэшируются, персональные ответы остаются private/no-store.
- Автофокус поиска сбрасывал прокрутку при возврате. Фокус больше не прокручивает страницу; новые link-переходы начинают страницу сверху, back/forward сохраняет позицию.
- Успешные уведомления держались 6,5 секунды: теперь 1,8 секунды без очереди, ошибки остаются до закрытия и объявляются отдельно. Статус рекомендаций содержал буквальную строку «Доступн...» — восстановлено полное время.
